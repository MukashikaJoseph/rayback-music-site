# RAYBACK Music 2.0 — Official Website

This repository contains the static landing page for RAYBACK Music 2.0.

## Status

The application is under active development. This website is its public project homepage and does not imply that the application is publicly released.

## Website files

- `index.html` — page structure and content
- `styles.css` — responsive dark/purple visual styling
- `script.js` — mobile navigation and dynamic footer year

## Local preview

Open `index.html` in a modern web browser. No build step or package installation is required.

## Deployment

The site is designed for GitHub Pages. Configure GitHub Pages in the repository settings to publish from the `main` branch and the repository root.
